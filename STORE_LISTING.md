# Roku beta listing

## Channel name

Family Dashboard

## Short description

Turn your Roku TV into a family dashboard powered by Home Assistant.

## Full description

Family Dashboard brings the information your family checks every day to the
television. See today's and tomorrow's calendar, meals, indoor and outdoor
climate, weather forecasts, lights, scenes, security controls, and family
home/away status in a clear, remote-friendly interface.

The companion Home Assistant integration provides secure device approval,
live updates, configurable entities, seasonal backgrounds, theme colors, and
calendar settings. Roku devices receive their own revocable credential and do
not store a Home Assistant long-lived access token.

## Features

- Home dashboard with calendar, meals, climate, and next holiday
- Monthly calendar and standalone multi-day week calendar
- Daily or hourly weather forecasts
- Optional second weather location for shorter forecasts
- Lights, switches, scenes, and climate controls
- Security tab for garage doors, locks, alarm status, and family presence
- Seasonal or uploaded Home Assistant backgrounds
- Remote-friendly navigation and five-minute return to Home

## Requirements

- Roku device or Roku TV with FHD support
- Home Assistant on the same reachable network, with the Family Dashboard
  integration installed
- Selected Home Assistant entities configured in the integration
